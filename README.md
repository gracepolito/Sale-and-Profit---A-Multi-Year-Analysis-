# 📊 Sales and Profit — A Multi-Year Analysis (Tableau)

Interactive Tableau workbook analyzing **multi-year sales and profit trends** across regions and product categories.  
The project explores KPI changes, regional performance, and profit-to-sales relationships.

---

## 🧰 Tools & Techniques
- **Software:** Tableau Desktop  
- **Data Source:** Multi-year retail sales dataset (embedded in `.twbx`)  
- **Visuals:** KPI summary dashboard, regional maps, area charts, dual-axis combo charts  
- **Focus:** Executive insights for CEO & CMO, including recommendations for top-performing regions and products

---

## 📂 File
**`Sales and Profit - A Multi Year Analysis.twbx`**  
Packaged Tableau workbook — simply open in Tableau Desktop to view dashboards and story points.

---

## 🚀 How to Use
1. Download the `.twbx` file from this repository.  
2. Open it in **Tableau Desktop**.  
3. Explore dashboards to interact with filters and time-based visuals.
